# uNCov Website – Landing Page

A modern, responsive landing page built using **Next.js**, **Tailwind CSS**, **TypeScript**, and styled with **Skipper UI** for rapid development and professional design.

## Features

- Built with Next.js for robust and scalable React web applications.
- Styled using Tailwind CSS for utility-first, responsive design.
- Fully typed codebase with TypeScript for reliability and maintainability.
- Integrated Skipper UI component library for high-quality, ready-to-use UI components.
- Modern landing page layout and responsive features.
